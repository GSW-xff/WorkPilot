# ADR-003：先保留单 Agent DAG，不提前引入多 Agent

- 状态：Accepted
- 日期：2026-10-10

## 决策

WorkPilot V3 继续使用一个结构化 Planner 和确定性 Executor/Verifier，不把每个步骤包装成
独立“Agent”。并行度由 DAG 和 Temporal Activity 表达，权限由 Policy/Adapter 边界表达。

## 原因

当前固定评测集尚没有证明多 Agent 能在质量、成本或恢复能力上胜过单 Agent。提前加入
Supervisor/Worker 对话会增加上下文复制、Token 成本、Trace 关联、权限委托和失败恢复复杂度，
却不自动改善业务结果。

## 触发重新评估的条件

只有出现至少一种需求才开展消融实验：需要独立权限域、相互隔离的长上下文、不同模型专长，
或可并行且能显著缩短关键路径的子任务。实验必须在同一版本数据集上报告成功率、安全违规、
P95、Token/成本和方差；没有统计或业务显著收益就不合并多 Agent 架构。

## 后果

面试展示可以解释并发与角色边界，但不会把“Agent 数量”当成果。未来实验应作为独立 ADR，
不得把尚未运行的消融写成当前能力。
