# WorkPilot

WorkPilot 是一个面向企业跨系统办公流程的多模态任务执行 Agent。项目当前处于 MVP 设计阶段。

项目的核心目标不是提供一个通用聊天助手，而是让用户能够把自然语言目标交给系统，由系统完成可规划、可审批、可验证、可恢复和可审计的跨系统操作。

详细方案见：[MVP 完整实现方案](docs/mvp-implementation-plan.md)。
